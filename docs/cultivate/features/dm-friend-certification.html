DM/フレンド許可取り

DM・フレンド申請をパネルからワンクリックで受け付け、承認状況を一覧管理

概要

DM/フレンド許可取り機能は、サーバーメンバーからの DM・フレンド申請 をパネルボタンで受け付け、 申請者の許可状況（許可済み / 未承認 / 送信済み）を一覧で確認できる機能です。

申請種別は DM / フレンド / 鯖内DM / 鯖内フレンド の4種類。 申請時に「一言」を添えることができ、承認時の通知文・許可取り時の 案内文もテンプレートとして自由に設定できます。

💡 ユースケース: 界隈サーバーで「DM許可」「フレンド許可」を 募りたい場合に活用できます。パネルに各申請ボタンを設置し、申請者は ボタンを押して種別と一言を入力するだけで申請完了です。

機能詳細

DM/フレンド許可設定

「どの種別の申請を受け付けるか」「誰が申請できるか」をまとめた設定です。 1サーバーに複数作成でき、パネルに紐付けられます。

  • 種別: DM / フレンド / 鯖内DM / 鯖内フレンド を複数選択
  • 許可ロール / 不許可ロール: 申請できるメンバーをロールで制限
  • 許可取りテンプレ文: 申請時に送られる案内文
  • 承認テンプレ文: 承認時に送られる通知文

許可 / 不許可ロール判定

許可ロール・不許可ロールを設定することで、申請できるメンバーを制限できます。 判定は以下の通りです。

許可ロール 不許可ロール 判定
未設定 未設定 全員 が申請可能
設定あり 未設定 許可ロールを いずれか1つ 保持している人のみ
未設定 設定あり 不許可ロールを いずれも保持していない 人のみ
設定あり 設定あり 不許可ロール優先（不許可ロール保持者は申請不可）

DM/フレンド許可パネル

パネルは Embed + ボタンで構成され、任意のチャンネルに設置できます。

  • パネル設定: Embed の色（#RRGGBB）と説明文を設定
  • ボタン設定: 「確認」ボタンと各許可設定の申請ボタンを配置。 ボタンごとに色（緑・赤・青・グレー）・絵文字・ラベルを設定可能
  • テンプレ文設定: 「確認」「デフォルト」および紐付けた許可設定ごとに 許可取りテンプレ文・承認テンプレ文を設定
  • 設置: 送信先チャンネルを選択してパネルを送信。 送信後も「🔄 パネル更新」で内容を更新可能

確認ボタン（状態一覧のDM送信）

パネルの「確認」ボタンを押すと、申請者の DM に現在の申請状況が Embed 形式で送信されます。一覧はページ送りに対応しており、 申請が増えてもすべて確認できます。

  • 許可済みDM / 許可済みフレンド（鯖内版を含む）
  • 未承認DM / 未承認フレンド（鯖内版を含む）
  • 送信済みDM / 送信済みフレンド（鯖内版を含む）

設定手順

  1. DM/フレンド許可設定を作成 /dmフレンド許可設定 を実行（管理者専用）し、 「➕ 新規作成」から設定名と種別（DM / フレンド / 鯖内DM / 鯖内フレンド）を選択
  2. 許可ロールを設定（任意） 編集画面の「✅ 許可ロール設定」で許可・不許可ロールを設定
  3. テンプレ文を設定（任意） 「📝 テンプレ文設定」で許可取り時・承認時の文面を設定
  4. 保存 「💾 保存」で設定を確定
  5. パネル設定を作成 /dmフレンド許可パネル設定 を実行し、 「➕ 新規作成」から設定名と紐付ける許可設定を選択
  6. パネルをカスタマイズ 「🖼️ パネル設定」（色・説明文）「🔘 ボタン設定」（ボタン色・絵文字・ラベル） 「📝 テンプレ文設定」で内容を調整
  7. パネルを設置 「📍 設置」で送信先チャンネルを選択して送信
  8. 保存 忘れずに「💾 保存」をクリック

ユーザーの操作フロー

  1. 申請ボタンをクリック 設置されたパネルの申請ボタン（例: 「📝 許可申請#1」）を押す
  2. 種別と一言を入力 表示されるモーダルで種別（DM / フレンド / 鯖内DM / 鯖内フレンド）を選択し、 必要に応じて一言を入力して送信
  3. 申請完了 「✅ 許可申請を受け付けました。」と表示され、申請が記録されます
  4. 状況を確認 パネルの「✅ 確認」ボタンを押すと、DM に現在の申請状況一覧が届きます

コマンド

/dmフレンド許可設定
DM/フレンド許可設定のプリセットを管理します（新規作成・編集・削除）
管理者専用
/dmフレンド許可パネル設定
DM/フレンド許可パネル設定のプリセットを管理・設置します
管理者専用

設定項目一覧

項目 説明
設定名 管理用の設定名（ユーザーには非表示）
種別 DM / フレンド / 鯖内DM / 鯖内フレンド（複数選択可）
許可ロール 申請を許可するロール（未設定なら全員）
不許可ロール 申請を拒否するロール（未設定なら制限なし）
許可取りテンプレ文 申請時に送られる案内文（変数: {type} {profile_link} {comment}）
承認テンプレ文 承認時に送られる通知文（変数: {nickname} {profile_link} {type}）
Embed 色 パネルのアクセントカラー（#RRGGBB 形式）
Embed 説明文 パネルに表示する説明文
ボタン色 / 絵文字 / ラベル 各申請ボタン・確認ボタンの見た目（ボタンごとに設定）

テンプレート変数

変数 説明 使用可能なテンプレ
{type} 申請種別（DM / フレンド / 鯖内DM / 鯖内フレンド） 許可取り / 承認
{profile_link} 申請者のプロフィールリンク 許可取り / 承認
{comment} 申請時の一言 許可取り
{nickname} 申請者の表示名 承認

💡 デフォルトテンプレート: 「デフォルト」には初期値として 以下の文面が設定されています。各許可設定のテンプレ文は、デフォルトを 基準に個別に上書きできます。

【種別】{type}
【プロフィール】{profile_link}
【一言】{comment}
-----
[{nickname}]({profile_link})さんへの{type}許可申請が承認されました。
-----

注意事項

⚠️ 注意:

  • 申請記録はサーバーごと・パネルごとに保存されます
  • 確認ボタンの状態一覧は、押した本人の DM にのみ送信されます（DM を 許可していない場合は送信できません）
  • プロフィールリンクは、パネルが設置されているサーバーに プロフィールがある場合はそのリンクが優先表示されます
  • プリセット数には上限があります（許可設定: 無料5 / プレミアム20、 パネル設定: 無料3 / プレミアム10）
