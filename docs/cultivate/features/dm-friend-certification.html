DM/フレンド許可取り

チャットで「DMいいですか？」と聞く手間をBot化。相手を指定してDMで許可を取り、結果を記録・管理

概要

DM/フレンド許可取り機能は、メンバーを指定してその相手にDMで許可を取る システムです。これまでチャットで「DMいいですか？」「フレンドいいですか？」と 手動で聞いていた行為を、Botが代行します。

申請者はパネルのボタンを押し、相手（受信者）を選択して一言を添えるだけで、 受信者のDMに承認/却下ボタン付きの申請が届きます。受信者の返答は送信者に自動通知され、 記録（送信・承認・却下の日時）が自動で蓄積されます。

申請種別は DM / フレンド / 鯖内DM / 鯖内フレンド の4種類に固定です。

💡 ユースケース: 界隈サーバーで「この人とDMつなぎたい」 「フレンド申請していいか聞きたい」という場面で活用できます。パネルに各申請ボタンを設置し、 申請者は相手を選んで送信するだけ。相手はDM内のボタンで承認/却下できます。

機能詳細

DM/フレンド許可設定（固定4種別）

許可設定は DM / フレンド / 鯖内DM / 鯖内フレンド の4種別に固定です。 新規作成・削除はできません。それぞれに対して「誰が申請できるか」とテンプレ文を設定します。

  • 種別: DM / フレンド / 鯖内DM / 鯖内フレンド（固定・変更不可）
  • 許可ロール / 不許可ロール: 申請できるメンバーをロールで制限
  • 許可取りテンプレ文: 受信者のDMに送られる案内文
  • 承認テンプレ文: 承認時に送信者へ送られる通知文

許可 / 不許可ロール判定

許可ロール・不許可ロールを設定することで、申請できるメンバーを制限できます。 判定は以下の通りです。

許可ロール 不許可ロール 判定
未設定 未設定 全員 が申請可能
設定あり 未設定 許可ロールを いずれか1つ 保持している人のみ
未設定 設定あり 不許可ロールを いずれも保持していない 人のみ
設定あり 設定あり 不許可ロール優先（不許可ロール保持者は申請不可）

DM/フレンド許可パネル

パネルは Embed + ボタンで構成され、任意のチャンネルに設置できます。

  • パネル設定: Embed の色（#RRGGBB）と説明文を設定
  • ボタン設定: 「確認」ボタンと各許可種別の申請ボタンを配置。 ボタンごとに色（緑・赤・青・グレー）・絵文字・ラベルを設定可能
  • テンプレ文設定: 「確認」「デフォルト」および紐付けた許可種別ごとに 許可取りテンプレ文・承認テンプレ文を設定
  • 基本設定: 許可種別選択（DM / フレンド / 鯖内DM / 鯖内フレンド）、 通知方法（DM / DM→スレッド / スレッド）、 スレッド通知用TC、ログ通知TC（運営用）、自動連動申請オプションを設定
  • タイプラベル設定: パネル上の表示名を DM / フレンド / 鯖内DM / 鯖内フレンド のそれぞれでカスタマイズ
  • 設置: 送信先チャンネルを選択してパネルを送信。 送信後も「🔄 パネル更新」で内容を更新可能

基本設定（許可種別・通知方法・ログ通知・自動連動申請）

パネル設定の「⚙️ 基本設定」（最初のボタン）から、紐付ける許可種別と 申請の届き方・付随機能を設定できます。

  • 許可種別: DM / フレンド / 鯖内DM / 鯖内フレンド の中から パネルに紐付ける種別を複数選択できます（最大4種別）
  • 通知方法:
    • DM: 受信者と送信者のDMに申請・通知を送信（既定）
    • DM→スレッド: DMにも届けつつ、スレッド通知用TCにも申請を展開
    • スレッド: スレッド通知用TCにスレッドを自動生成して通知 （未設定ならパネル設置TC。スレッド内に設置したパネルは親TCが使用されます）
  • スレッド通知用TC: スレッドを作成するチャンネルを指定。 未選択の場合はパネルを設置したチャンネル（スレッド内設置時は親TC）が使われます
  • ログ通知TC（運営用）: 承認・却下・取り消しの履歴を通知する チャンネルを指定。未選択の場合はログを残しません。
    🔒 ログTCに残るのは 鯖内DM・鯖内フレンド のみです。 DM・フレンド（全サーバー共通）の開通情報は、他サーバーで開通した事実が このサーバーに漏れるのを防ぐためログTCには出さず、当事者への DM 通知のみで 通知されます。
  • その他オプション:
    • フレンド申請時にDM開通申請も行う: フレンド申請の際、 相手とのDMが未開通ならDM開通申請を同時に送信します
    • 鯖内フレンド申請時に鯖内DM開通申請も行う: 鯖内フレンド申請の際、 鯖内DMが未開通なら鯖内DM開通申請を同時に送信します

「開通済み」の判定は、相手との間で申請を送り、承認された場合に 成立します（送信済み・却下済み・未送信では開通扱いになりません）。逆向き （相手から送られてきて自分が承認）でも開通済みと判定されます。

申請ボタンで相手を選択した時点で開通済みかどうかを判定し、 既に開通済みの相手には申請を送信できません。 その場合は「相手は既に◯◯が開通済みのため、申請は不要です」と表示され、 申請メッセージは送られません。

タイプラベル設定

パネル設定の「🏷️ タイプラベル設定」から、以下の4つのラベルを自由に変更できます。 既定値は DM / フレンド / 鯖内DM / 鯖内フレンド です。

キー 既定ラベル
dm DM
friend フレンド
guild_dm 鯖内DM
guild_friend 鯖内フレンド

設定したラベルは、パネルのボタンラベル・申請種別一覧・テンプレ変数 {type}・通知メッセージ内の「DM」「フレンド」等の表記に反映されます （未設定の場合は既定ラベルが使われます）。

確認ボタン（自分が送った申請の一覧）

パネルの「確認」ボタンを押すと、そのボタンを押した本人が送信した申請の 状況が Embed 形式で送信されます。申請があるカテゴリのみが送信され、 データが無い種別は最後に「ℹ️ データの無い種別」としてまとめて表示されます （送信数が削減されます）。15件を超えるカテゴリは複数Embedに分割されます。

通知先はパネル設定に応じます:

  • DM / フレンド種別が設定されている場合: 情報漏洩防止のため、一律で送信者の DM に送信します （スレッドやサーバー内チャンネルには出さない）
  • 鯖内DM / 鯖内フレンドのみの場合: 基本設定の通知方法に従います。「DM」= 送信者DM、「DM→スレッド」= DM + スレッド、「スレッド」= スレッド通知用TC（未設定ならパネル設置TC/親TC）にスレッドを建てて送信
  • ✅ 承認済み：DM / 鯖内DM / フレンド / 鯖内フレンド
  • ⏳ 送信済み：DM / 鯖内DM / フレンド / 鯖内フレンド
  • ❌ 却下済み：DM / 鯖内DM / フレンド / 鯖内フレンド

各行は [受信者名](プロフィールリンク)（名前/送信日時/承認日時） 形式で表示され、 DM・フレンドの許可済みにはサーバー名も表示されます。

設定手順

  1. DM/フレンド許可設定を確認 /dmフレンド許可設定 を実行（管理者専用）すると、 DM / フレンド / 鯖内DM / 鯖内フレンド の4種別が自動で表示されます
  2. 許可ロールを設定（任意） 各種別の「✏️ 編集」→「✅ 許可ロール設定」で許可・不許可ロールを設定
  3. テンプレ文を設定（任意） 「📝 テンプレ文設定」で許可取り時・承認時の文面を設定
  4. 保存 「💾 保存」で設定を確定
  5. パネル設定を作成 /dmフレンド許可パネル設定 を実行し、 「➕ 新規作成」から設定名と紐付ける許可種別を選択
  6. 許可種別を調整（任意） 「⚙️ 基本設定」の許可種別で、パネルに紐付ける種別を変更できます
  7. パネルをカスタマイズ 「⚙️ 基本設定」（許可種別・通知方法・ログTC・自動連動） 「🖼️ パネル設定」（色・説明文）「🔘 ボタン設定」（ボタン色・絵文字・ラベル） 「📝 テンプレ文設定」「🏷️ タイプラベル設定」で内容を調整
  8. パネルを設置 「📍 設置」で送信先チャンネルを選択して送信
  9. 保存 忘れずに「💾 保存」をクリック

ユーザーの操作フロー

送信者（許可を取りたい人）

  1. 申請ボタンをクリック 設置されたパネルの申請ボタン（例: 「💬 DM許可」「🤝 フレンド許可」）を押す
  2. 相手を選択して一言を入力 表示されるモーダルで「相手（受信者）」を選択し、必要に応じて一言を入力して送信
  3. 送信完了 「📤 許可申請を送信しました。」と表示され、受信者のDMに申請が届きます
  4. 送信者にも通知 自分のDMに「📤 送信しました」通知（✏️ 編集 / 🗑️ 取り消しボタン付き）が届きます
  5. 承認/却下の通知 相手が承認/却下すると、その結果と日時が自分のDMに通知されます
  6. 状況を確認 パネルの「✅ 確認」ボタンを押すと、自分が送った申請の一覧が DM に届きます

受信者（許可を求められた人）

  1. 申請を受け取る DMに承認/却下ボタン付きの許可取りメッセージが届きます
  2. 承認または却下 「✅ 承認」または「❌ 却下」ボタンを押すだけで完了。結果は送信者に自動通知されます

注意事項

⚠️ 注意:

  • 許可設定は DM / フレンド / 鯖内DM / 鯖内フレンド の4種別に固定されており、 新規作成・削除はできません
  • 申請記録はサーバーごと・パネルごとに保存され、送信・承認・却下の日時が保持されます
  • 送信後も、送信者DMの「✏️ 編集」で一言を変更、「🗑️ 取り消し」で申請を取り下げられます （取り消し時は受信者にも通知されます）
  • 承認済み・却下済みの申請の編集・取り消しはできません
  • 確認ボタンの状態一覧は本人が送信した申請のみ表示されます。 DM / フレンド種別を含むパネルでは必ず本人の DM に送信され、 鯖内種別のみのパネルでは基本設定の通知方法に従います。 一覧はボタン付きではないため、送信後に追加された申請を表示するには 再度確認ボタンを押してください
  • スレッド通知でスレッドを作成する際、パネル設置時のボタンがそのままスレッド内に送信されます。 通知方法が「スレッド」の場合、送信者への通知も受信者と同じスレッドに届きます
  • 自動連動申請は相手との間で「承認済み」の申請が1件も無い場合にのみ実行されます。 逆向き（相手から送られて自分が承認）の承認でも開通済みと判定されます
  • プロフィールリンクは、パネルが設置されているサーバーに プロフィールがある場合はそのリンクが優先表示されます
  • パネル設定のプリセット数には上限があります（無料3 / プレミアム10）
