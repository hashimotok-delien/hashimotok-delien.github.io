BUMP通知

DISBOARD / ディス速のBUMPを検知して自動通知

💡 BUMP通知とは？ DISBOARD やディス速でサーバーが BUMP（宣伝）されたことを検知し、 お礼メッセージを自動送信する機能です。 さらに 2時間後 に「BUMPの時間だよ」と 次回の BUMP を促す通知も自動で行います。

概要

設定したチャンネルで DISBOARD の /bump または ディス速の /up が実行されると、実行結果の Embed を 検知して自動でメッセージを送信します。

  • DISBOARD / ディス速をそれぞれ個別に設定可能
  • 日中・深夜でメッセージを自動切り替え
  • サーバーごとの累計BUMP回数をメッセージに反映
  • BUMPから2時間後に「BUMPの時間だよ」通知を自動送信
  • タイマー通知も日中・深夜で切り替え可能
  • タイマーメッセージを空欄にすると通知なし（タイマーは消化）

設定方法

設定パネルを開く

  1. コマンドを実行 /bump通知設定
  2. サービスごとに設定 「📢 DISBOARD通知設定」「⚡ ディス速通知設定」ボタンから 検知チャンネル・メッセージ・深夜時間帯を設定
  3. タイマー通知を設定（任意） 「⏰ タイマー設定」ボタンから2時間後通知のメッセージを設定

設定項目

設定項目 必須 説明
BUMPチャンネル 任意 BUMPを検知するテキストチャンネル（未選択時は通知なし）
日中メッセージ 任意 BUMP検知時の日中メッセージ（未設定時はデフォルト）
深夜メッセージ 任意 BUMP検知時の深夜メッセージ（未設定時はデフォルト）
深夜開始時刻 任意 深夜時間帯の開始時刻（HH:MM 形式、デフォルト: 22:00）
深夜終了時刻 任意 深夜時間帯の終了時刻（HH:MM 形式、デフォルト: 06:00）
タイマー日中メッセージ 任意 2時間後の日中通知メッセージ（空欄時は通知しない）
タイマー深夜メッセージ 任意 2時間後の深夜通知メッセージ（空欄時は通知しない）

DISBOARD とディス速はそれぞれ独立して設定できます。 一方のサービスだけ設定して使用することも可能です。

動作の流れ

BUMP検知時

  1. BUMPを検知 設定チャンネルで DISBOARD / ディス速の実行結果メッセージを検知
  2. 履歴を記録 実行ユーザー・実行日時・サービスをデータベースに記録し、 累計BUMP回数をカウント
  3. お礼メッセージを送信 現在時刻に応じて日中/深夜メッセージを選択し、その場のチャンネルに送信
  4. タイマーを登録 2時間後の「BUMPの時間だよ」通知タイマーを自動登録

2時間後（タイマー通知）

  1. バックグラウンドで監視 1分間隔で通知時刻を過ぎたタイマーをチェック
  2. 通知を送信 時刻に応じて日中/深夜のタイマーメッセージを送信 （メッセージ未設定の場合は送信せずタイマーのみ消化）

メッセージに使えるプレースホルダー

プレースホルダー 置き換え内容
{user} BUMP実行ユーザーのメンション（タイマー通知で使用）
{member} BUMP実行ユーザーの表示名
{count} そのサーバーでの累計BUMP回数
{time} 次回BUMP可能時刻（<t:unix:t> 形式）
{usernickname} BUMP実行ユーザーの表示名（デフォルトメッセージで使用）

デフォルトメッセージ（DISBOARD・日中）

### {usernickname}さんBUMPありがと！
表示順があがったよ～！

### BUMP回数が更新されました
{count}回目のBUMP

2時間後(<t:{time}:t>)にBUMP通知します。

デフォルトタイマーメッセージ（DISBOARD・日中）

{user} BUMPの時間だよ！
</bump:947088344167366698>を実行してね！

BUMP通知設定パネルを開きます。 DISBOARD / ディス速の検知チャンネル・メッセージ・ 深夜時間帯・タイマー通知を設定できます。
管理者専用

注意事項

  • BUMPチャンネルが未設定の場合は検知・通知は行われません
  • 検知チャンネルはサービスごとに1つまで設定できます
  • BUMPを実行したユーザーを特定できない場合は、メッセージは ユーザーなし（{user} は「誰か」）で送信されます
  • タイマー通知のメッセージが空欄の場合は通知されませんが、 タイマー自体は消化されるため重複通知はありません
  • タイマー通知はBUMP実行チャンネル（検知チャンネル）に送信されます
  • Botの再起動後も未通知のタイマーは復元され、通知が継続されます
