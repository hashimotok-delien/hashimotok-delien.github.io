# カスタムルームパネル 仕様書

> ステータス: **設計中（v0.1）**
> 最終更新: 2026-09-14
> 対象: `utils/system_cogs/custom_room_panel_cog.py`（新規システムコグ）

## 1. 概要

カスタムルームパネルは、**指定されたカテゴリ内のVCに人が初めて入ったとき**、
その**VC内チャット（VCのテキストチャンネル）にパネル（メッセージ＋ボタン）を自動投稿**する機能です。

- **VCの作成は行わない**（既存のVCに対して動作する）
- システムコグとして実装し、**モジュール単体で完結**させる
- 設定はサーバーごとに複数保持でき、**設定一覧（Paginator式）**で管理する
- 設定コマンド: `/カスタムルームパネル設定`（管理者専用）

### 1.1 用語

| 用語 | 説明 |
|---|---|
| パネル | インチャに自動投稿するメッセージ＋ボタン |
| 設定 | パネルの挙動を定義する1単位（設定名・該当カテゴリ・追加オプション） |
| カスタムルーム | 指定カテゴリ内の既存VC（人が入る対象。Botは作成しない） |
| インチャ（インチャット） | VCに付随するテキストチャンネル。`vc.send()` で送信可能 |
| 追加オプション | パネルのボタンから操作できる拡張機能（デフォルトOFF） |

## 2. コマンド

| コマンド | 権限 | 説明 |
|---|---|---|
| `/カスタムルームパネル設定` | 管理者 | 設定一覧パネルを開く |

- `@app_commands.default_permissions(administrator=True)`
- `@app_commands.guild_only()`
- `@app_commands.guilds(*Var.BETA_SYSTEM_GUILD_IDS)`

## 3. 動作フロー（パネル投稿）

### 3.1 トリガー

- `on_voice_state_update` イベントで、**指定カテゴリ内のVC**への入退室を監視する

### 3.2 「初めて入った時」の定義

- **VCが0人（空）の状態から、最初の1人が入室した時**を「初めて入った時」とする
- 既に誰かがいるVCへの追加入室では投稿しない
- 全員退出して空になった後、再度入室があれば再投稿する

### 3.3 投稿フロー

```
[入室検知] 指定カテゴリ内のVCが 0人 → 1人以上 になった
  → そのVCのインチャを取得
  → パネル（メッセージ＋ボタン）を投稿
  → （パネル投稿遅延設定がONなら指定秒数待ってから投稿）
```

- 投稿先: VCに紐づく**インチャ（インチャット）**
- インチャへの送信は `await vc.send(...)` を使用する
  （VCにチャットが付随しているため `message.channel.id == vc.id` が成立）
- **多重投稿防止は行わない**（「メニュー」を送信しても何度でも送信して良い）

## 4. 設定一覧画面

`/カスタムルームパネル設定` 実行時に **Paginator** で表示する（1ページ＝1設定）。

### 4.1 表示内容（Embed）

- タイトル: `🎛️ {設定名}`
- 色: 有効な設定は緑 / 無効は赤
- 有効/無効表示: `✅ 有効` / `🔴 無効`
- フィールド:
  - **該当カテゴリ**: 設定されたカテゴリ一覧（`#カテゴリ名` 形式）
  - **同名カテゴリ有効化**: 🟢/🔴
  - **追加オプション**: 有効化されているオプション一覧（無ければ `なし`）
- フッター: `{ページ}/{総ページ} | 合計: {N}件`

### 4.2 ページボタン（各ページ共通）

| ボタン | スタイル | 動作 |
|---|---|---|
| ✏️ 編集 | secondary | そのページの設定の編集画面へ遷移 |
| ➕ 新規作成 | green | 新規作成Modalを開く |
| 🗑️ 削除 | danger | YES/NO確認 → そのページの設定を削除 |
| ❌ 閉じる | danger | パネルを閉じる |

- 設定が0件のときは「設定がありません」Embed＋**新規作成ボタンのみ**表示
- 実装は `schedule_message_cog.py` の `_show_settings_paginator` を踏襲

## 5. 新規作成フロー

### 5.1 基本設定Modal

「➕ 新規作成」ボタン → **基本設定Modal** を開く。

| 項目 | コンポーネント | 必須 | 備考 |
|---|---|---|---|
| 設定名 | TextInput | ✅ | 重複可能（同名OK） |
| 該当カテゴリ | ChannelSelect（category） | ✅ | 複数選択可 |
| 同名カテゴリでも有効化 | CheckboxGroup | 任意 | デフォルト **False** |

- Modal内アイテムは3つ（上限5以内に収まる）
- **送信すると編集画面へ遷移**する（Modalチェーンは不可のため、Modal送信後はViewへ）

### 5.2 新規作成時の初期値

- 設定名: 入力値
- 該当カテゴリ: 選択したカテゴリIDリスト
- 同名カテゴリでも有効化: チェック状態
- 追加オプション: **全てOFF**

### 5.3 遷移

```
新規作成ボタン → 基本設定Modal → 送信
  → 設定をDB保存（仮保存）
  → 編集画面（View）へ遷移
```

## 6. 編集画面

「✏️ 編集」ボタン、または新規作成Modal送信後に表示する**編集画面（View）**。

### 6.1 画面構成

- **Embed**: 設定名・該当カテゴリ・同名カテゴリ有効化・追加オプション状態・保存状態（💾未保存/✅保存済み）
- **Select1（追加オプション選択）**: 複数選択可。デフォルト全てOFF
- **Select2（各種設定）**: 基本設定＋有効化されたオプションの詳細設定項目
- **ボタン**: 💾保存 / ↩️戻る

### 6.2 基本設定の編集

Select2 に基本設定の編集項目を配置する。

| 項目 | コンポーネント | 備考 |
|---|---|---|
| 📛 設定名変更 | Modal（TextInput） | 重複可能 |
| 🗂 該当カテゴリ変更 | Modal（ChannelSelect） | 複数選択可・必須 |
| 🔁 同名カテゴリ有効化 | トグル（Select2でON/OFF） | デフォルトFalse |

### 6.3 追加オプション設定（Select1方式）

ランク設定（`rank_cog.py` の `_RankPresetEditorView`）の
**Select1（機能モジュール複数選択）方式**を踏襲する。

- Select1 でオプションを複数選択 → 選択状態を即時反映（dirty化）
- 各オプションは `discord.SelectOption` の `default` でON/OFFを表現
- 選択項目は「🟢」未選択項目は「🔴」をSelectのオプション絵文字に使用
- オプションがONになると、Select2 にそのオプションの**詳細設定項目**が追加される
- オプションがOFFのときは詳細設定項目は表示されない

```
Select1（追加オプション）: 複数選択可
  ├─ カスタムチャンネル名  ─┐
  ├─ 名前変更可能        │ ON時のみ
  ├─ 絵文字変更可能       │ Select2に
  ├─ カテゴリ移動可能     │ 詳細設定が
  ├─ 人数変更可能         │ 追加表示
  ├─ ビットレート変更可能  │
  ├─ ステータス変更可能   │
  ├─ ノック部屋           │
  ├─ パネル投稿遅延設定   │
  ├─ パネル再投稿メッセージ│
  └─ 寝落ち送り          ─┘
```

| 6 | ビットレート変更可能 | パネルのボタンからVCのビットレートを変更できる | 7.7 |

### 7.2 カスタムチャンネル名

- 人数変更時に自動的にその人数に合わせてVC名も変更する
- **名前変更可能との共存は不可**（同時ON不可）

### 7.3 名前変更可能

- 入力した名前に変更が可能
- デフォルトは現在のVC名が入力される

### 7.4 絵文字変更可能

- 絵文字とその説明，ラベルが設定できてセレクトにてそれが表示される
- **設定で絵文字の登録が可能**（登録した絵文字がセレクトに表示される）
- 絵文字を最大何個まで付けれるかの設定が可能（0で全て）

### 7.5 カテゴリ移動可能

- 各カスタムルームパネル設定を選択出来て、それが登録しているカテゴリの一番上への移動が可能
- `category.channels` の数が50の場合は次のカテゴリへ

### 7.6 人数変更可能

- 入力欄に入力した人数にVC上限を設定可能
- 空欄もしくは0以下は無制限，100以上は99とする
- チェックボックスで**Bot数を考慮する**を有効にすると、人数を5としたときにVCにいるBot数が3だったら上限を8にする
- **設定上限・設定下限**を設定可能でこの範囲外の数にはできない
- Bot数を考慮するがONの場合はそのBot数の数までは入力禁止としない

### 7.7 ビットレート変更可能

- 上下限設定は可能。空欄ならDiscordデフォルトのビットレート上下限で設定可能
- 単位は「kbps」で64と入力したら `bitrate=64000` で編集を行う
- 上限は設定上限とは別で**サーバーのブーストレベル**によっても変更されるので注意
  - デフォルト：8～96kbps
  - 1レベル：8～128kbps
  - 2レベル：8～256kbps
  - 3レベル：8～384kbps

### 7.8 ステータス変更可能

- 詳細設定項目は特になし
- discordの仕様上Botから現在のステータスは取得できないので常に入力欄は空欄とする

### 7.9 ノック部屋

- ノックボタン絵文字・ラベル・色設定可能
- **move_members権限**を持っている人が承認なしで入れるかどうかのチェックボックス（デフォルトは入れる）
- **絵文字変更に「🚪」を追加するかどうか**（デフォルトはTrue）
  - 有効の場合は絵文字変更セレクトの一番上に 絵文字：🚪，ラベル：ノック部屋，説明：ノック部屋を切り替えます を表示
  - 絵文字変更がOFFでもこの項目がONなら🚪のみセレクトに表示する

### 7.10 パネル投稿遅延設定

- 入室から何秒後にパネルを表示するかどうか
- デフォルトは0で即投稿する
- **TextInputの形式で整数を入力**する。**0～30の範囲**で入力可能

### 7.11 パネル再投稿メッセージ

- デフォルトは「メニュー」
- インチャで「メニュー」とだけ投稿するとパネルを投稿する
- 空欄にすると投稿されない

### 7.12 寝落ち送り

- 寝落ち送り設定のどの設定を使用するのかを指定する
- そのカテゴリが寝落ち送り設定で登録されてなくても実行する

## 8. パネル操作（ボタン構成）

パネル（インチャに投稿されるメッセージ）には、追加オプションに応じたボタンが配置される。

### 8.1 パネル本体（Embed）

- **Embed** で構成
- `Embed.title` = `カスタムルームパネル`
- `Embed.description`:
  ```
  [⚙️チャンネル編集]ボタン押下で部屋名やビットレート変更などができるパネルを表示します。
  -# このパネルは「メニュー」と投稿することで再度表示することが可能です。
  ```
- `Embed.color` = `0xfdf682`
- ボタン: ラベル `⚙️チャンネル編集` / 色 緑

### 8.2 チャンネル編集メニュー（エフェメラル）

パネルの「⚙️チャンネル編集」ボタン押下で、**エフェメラル**のチャンネル編集メニューが表示される。

| ボタン | 動作 |
|---|---|
| チャンネル編集 | チャンネル編集Modalを開く |
| カテゴリ移動 | カテゴリ移動メニューを開く |

### 8.3 チャンネル編集Modal

「チャンネル編集」ボタン → **チャンネル編集Modal** を開く。
Modalには**有効化されているオプションのみ**項目が表示される。

| 項目 | コンポーネント | 表示条件 |
|---|---|---|
| 絵文字変更 | Select（絵文字選択） | 絵文字変更可能がON |
| チャンネル名 | TextInput | 名前変更可能がON |
| ステータス | TextInput | ステータス変更可能がON |
| 人数変更 | TextInput | 人数変更可能がON |
| ビットレート | TextInput | ビットレート変更可能がON |

- Modal内アイテムは最大5つ（上限5以内に収まる）
- 有効なオプションが0個の場合はModalを開かない（またはボタンを無効化）

### 8.4 カテゴリ移動

「カテゴリ移動」ボタン → **カテゴリ移動メニュー** を開く。

- 移動先は**この機能の設定**を選択する
- 設定Aから行ける設定先（設定B）も設定可能
  （設定Aのカテゴリ移動設定で移動先設定を指定する）
- 選択した設定で**有効となっているカテゴリ**にVCを移動する

#### 移動先設定UI

- 設定で選べる他のカスタムルームパネル設定を**Select**で表示する
- **最大25個**までの設定を選択できる

## 9. ノック部屋

ノック部屋オプションがONのとき、**チャンネル名に「🚪」を付けるとノック部屋**になる。

### 9.1 ノックボタン

- ノック部屋には、**常にインチャにノックボタンが最下部に表示**される
- ノックボタンを押下することで入室が可能になる

### 9.2 ノックの流れ

```
[ノック部屋に入りたい人]
  1. ノックボタンを押下
  2. インチャに「ノックした」ことが通知される
  3. 中にいる人が承認するまで待機
  4. 承認されると入室可能（自分で入るだけ）

[承認されない場合]
  → VCに入っても切断される
```

- そのVCに居ない人がそのVCに入るためには**ノックが必要**
- ノックをするとインチャにノックをしたことが通知される
- 中にいる人が承認しないと、その人はVCに入っても切断される
- **承認後の入室は本人が自分で入るだけ**（Botが移動させる処理は行わない）

### 9.3 承認UI

ノックが発生すると、VC内の人全員に承認メッセージが送信される。

- `content`: VC内の人全員メンション
- `Embed.title` = `ノックされました`
- `Embed.thumbnail` = `member.display_icon`
- `Embed.footer` = `ノック日時：yyyy/mm/dd HH:MM`
- `Embed.description`:
  ```
  {member.display_name}さんがノックをしました。
  30秒以内に承認されなければ，自動的に拒否されます。

  [プロフィールはこちら](リンク)
  ```
  - プロフv2のメインがあれば，「最後のプロフィールはコチラ」の部分も追加される
- 承認ボタン: 色=緑 / ラベル=`✅ 承認`
- 拒否ボタン: 色=赤 / ラベル=`❌ 拒否`
- 30秒以内に承認されなければ自動的に拒否される
- 承認された人は**自分でVCに入る**（Botが移動させる処理は行わない）

## 10. 寝落ち送り

寝落ち送りオプションがONのとき、パネルから寝落ち送りを実行できる。

### 10.1 連携

- `send_sleep_cog.py` と連携する
- **`send_sleep_cog.py` がない場合はこの機能を無効にする**（オプショナル依存）

### 10.2 動作

- パネルのボタン（寝落ち送り）を押下すると、**そのVC内の人**を寝落ち部屋に送る
- 寝落ち送りの仕様は `send_sleep_cog.py` を参考にする
  - 送り先: 寝落ち部屋VC（`send_sleep_cog` のプリセットで設定）
  - ロールチェック（送信拒否・切断・送りロール）を踏襲

### 10.3 ボタン構成

- **押せる条件**: VCにいること
- **対象者選択**: 通常Selectで表示
- 25人を超える場合は複数Select表示
- Selectの各オプション: ラベル=表示名 / 説明=`name` と `id` を記載

## 11. 削除フロー

「🗑️ 削除」ボタン → **YES/NO確認** → そのページの設定を削除する。

### 11.1 確認UI

- ボタン: **YES**（danger）/ **NO**（secondary）
- メッセージ: `「{設定名}」を削除しますか？`
- YES → 設定をDBから削除 → 設定一覧を再表示
- NO → 確認を閉じて設定一覧に戻る

### 11.2 削除時の注意

- 削除対象は**そのページの設定のみ**（ページ情報から設定IDを特定）
- 削除後は設定一覧（Paginator）を再構築して表示

## 12. データ設計

### 12.1 テーブル `custom_room_panel_settings`

```sql
CREATE TABLE IF NOT EXISTS custom_room_panel_settings (
    guild_id        BIGINT NOT NULL,
    panel_id        INT NOT NULL,
    name            VARCHAR(100) NOT NULL
                        DEFAULT '新しい設定',
    category_ids    JSON NOT NULL,      -- 該当カテゴリIDリスト
    allow_same_name TINYINT(1) NOT NULL
                        DEFAULT 0,      -- 同名カテゴリでも有効化
    options_json    JSON NOT NULL,      -- 追加オプション設定
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP
                        ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (guild_id, panel_id)
)
```

### 12.2 データクラス `CustomRoomPanelSetting`

```python
class CustomRoomPanelSetting:
    __slots__ = (
        "id", "name",
        "category_ids",      # List[int]
        "allow_same_name",   # bool
        "options",           # Dict[str, Any]（追加オプション）
    )
```

- `options` のデフォルト: 全オプションOFF

## 13. Modal制約への対応（共有メモ準拠）

`discord-dev-notes/discord-modal-chain-restriction.md` の制約を遵守する。

| 制約 | 本仕様での対応 |
|---|---|
| Modalチェーン不可（1インタラクションで `send_modal` は1回のみ） | 新規作成Modal送信後は**編集画面（View）へ遷移**。Modal→Modalの直接遷移はしない |
| Modal内で許可されるcomponent_type {4,5,6,7,10,12} | 基本設定Modalは TextInput(4) / ChannelSelect(8) / CheckboxGroup(22) のみ使用 |
| Modalのアイテム上限5つ | 基本設定Modalは3アイテムで収める |
| CheckboxGroup は `add_option()` で項目追加 | 同名カテゴリ有効化は `CheckboxGroup.add_option(label=..., value=..., default=False)` |
| Select系 `min_values=0` には `required=False` 必須 | 該当カテゴリは必須のため `min_values=1`（`required` 不要） |

### 13.1 基本設定Modalの実装イメージ

```python
class _BasicSettingModal(discord.ui.Modal, title="🎛️ 基本設定"):
    def __init__(self, ...):
        super().__init__()
        # 1. 設定名（必須）
        self.name_input = discord.ui.TextInput(
            label="設定名", required=True, max_length=100,
        )
        self.add_item(self.name_input)

        # 2. 該当カテゴリ（複数可・必須）
        self.category_select = discord.ui.Label(
            text="該当カテゴリ",
            component=discord.ui.ChannelSelect(
                placeholder="カテゴリを選択（複数可）",
                channel_types=[discord.ChannelType.category],
                min_values=1, max_values=10,
            ),
        )
        self.add_item(self.category_select)

        # 3. 同名カテゴリでも有効化（任意・デフォルトFalse）
        group = discord.ui.CheckboxGroup(custom_id="allow_same_name")
        group.add_option(
            label="同名カテゴリでも有効化",
            value="allow_same_name", default=False,
        )
        self.same_name_label = discord.ui.Label(
            text="同名カテゴリでも有効化",
            component=group,
        )
        self.add_item(self.same_name_label)
```

## 15. 実装方針メモ

- システムコグとして `utils/system_cogs/custom_room_panel_cog.py` に実装
- **VCの作成は行わない**。`on_voice_state_update` で入室を検知し、既存VCのインチャにパネルを投稿する
- インチャへの送信は `await vc.send(...)` を使用（`message.channel.id == vc.id`）
- ランク設定（`rank_cog.py`）の **Select1/Select2方式** を踏襲
  - Select1: 追加オプションの複数選択（デフォルトOFF）
  - Select2: 基本設定＋有効化されたオプションの詳細設定
- 設定一覧は `schedule_message_cog.py` の Paginator 方式を踏襲
- 削除は YES/NO 確認ボタン方式
- ノック部屋・寝落ち送りは `send_sleep_cog.py` 等と**オプショナル連携**（無い環境では無効化）
