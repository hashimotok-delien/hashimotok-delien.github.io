定期メッセージ

指定したチャンネルに一定間隔で自動投稿

💡 定期メッセージとは？ 指定したチャンネルへ、決めた間隔で 自動的にメッセージを投稿し続ける機能です。 常時掲示しておきたい案内・ルール・募集文などを 手動で投稿し直す必要がありません。

概要

定期メッセージ機能は、チャンネルごとに設定した メッセージを一定間隔（秒）で送信します。 送信間隔・本文・投稿者（Webhook）などを個別に設定でき、 投稿したメッセージを自動で削除する、といった 運用にも対応しています。

バックグラウンドループが5秒ごとに動作し、 前回の送信から設定した間隔を過ぎた設定を自動で処理します。

使い方の流れ

  1. /定期メッセージ設定 を実行 設定パネルを開き、「➕ 新規作成」から設定を追加します。
  2. 基本設定を行う 「🔗 基本設定」から設定名・送信先チャンネル・ 送信間隔（秒）を指定します。
  3. 投稿文を作成する 「📝 投稿文設定①／②」で本文や埋め込みを入力します。
  4. （任意）送信オプションを設定 「⏱️ 送信オプション」で自動削除までの秒数や 再投稿時の元メッセージ削除を設定します。
  5. 有効化して保存 「🟢 有効/無効」で有効にし、「💾 保存」で確定します。 以後、設定した間隔で自動投稿されます。

送信オプション（自動削除・再投稿時の削除）

編集画面の「⏱️ 送信オプション」から、投稿したメッセージの 扱いを設定できます。

  • 送信後、削除するまでの秒数 ：指定した秒数後にメッセージを自動削除します。 -1 を指定すると削除されません （自動削除なし）。0 以上で自動削除が有効になります。
  • 再投稿時に元のメッセージを削除 ：ON にすると、次の定期投稿の直前に前回のメッセージを 削除します。常に最新の1件だけを残したい場合に便利です。

投稿者設定（プリセット連携）

編集画面の「👤 投稿者設定」ボタンから、 投稿者設定 （/投稿者設定）で作成した投稿者プリセットを 選択できます。プリセットを選択すると、そのプリセットに 設定された表示名・アイコンが自動で適用され、 個別設定の名前・アイコンは入力不要です。

  • プリセットも名前・アイコンも未設定の場合は、 Botとして通常送信されます
  • 名前かアイコンのいずれかを設定すると、 Webhookとして送信されます
  • プリセットを後から編集すると、この定期メッセージにも 変更が自動反映されます

注意事項

  • 送信間隔は最小 10 秒です
  • Webhookを使用する場合、BotにWebhook管理権限が必要です
  • 「送信後、削除するまでの秒数」に -1 を指定すると 自動削除されません
  • 再投稿時の元メッセージ削除は、Bot／Webhook いずれの送信でも 自動的に判別して削除します
  • Botがメッセージを送信するには、対象チャンネルへの 送信権限が必要です
  • サーバーごとに登録できる設定数には上限があります
