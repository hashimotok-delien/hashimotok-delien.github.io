自動リアクション機能

メッセージ投稿時に自動でリアクションを追加

💡 自動リアクションとは？ 指定したチャンネルにメッセージが投稿された際に、 自動で特定の絵文字リアクションを追加する機能です。 コミュニケーションの活性化や特定のメッセージへの注意喚起などに 活用できます。

概要

自動リアクション機能は、設定したチャンネルにメッセージが投稿されると 自動で絵文字リアクションを付与します。 チャンネルごとに最大 20個 の絵文字を設定でき、 設定パネルから現在の設定確認・設定解除・ 既存メッセージへの再付与を行うことができます。

  • 設定はチャンネル単位で管理（コマンドを実行したチャンネルが対象）
  • 最大20個の絵文字を順番に登録可能
  • 設定パネルから現在の登録絵文字をいつでも確認可能
  • 設定解除・既存メッセージへの再付与はパネルのボタンからワンクリック
  • Bot のメッセージには自動リアクションを付与しません

設定方法

設定パネルを開く

  1. コマンドを実行 /自動リアクション設定
  2. 現在の設定を確認 対象チャンネルと登録済みの絵文字一覧がパネルに表示されます
  3. 操作する 「🗑️ 設定解除」で設定を解除、「➕ 再付与」で既存メッセージに 現在の設定でリアクションを付与できます

絵文字を登録する

  1. コマンドを実行 /自動リアクション設定 の emoji1〜emoji20 に付与したい絵文字を指定
  2. 既存メッセージにも付与する場合（任意） all_reaction を True にすると、 チャンネル内の既存メッセージ（最大200件）にも一括付与します

コマンド

/自動リアクション設定
自動リアクションの設定を行います。 絵文字を指定せずに実行すると設定パネルが表示され、 現在の設定確認・設定解除・再付与が行えます。
管理者専用

引数

引数 必須 説明
all_reaction 任意 True にすると既存メッセージ（最大200件）にも一括付与します（デフォルト: False）
emoji1〜emoji20 任意 付与する絵文字（最大20個）。すべて未指定で実行すると設定パネルを表示します

設定パネルのボタン

ボタン 説明
🗑️ 設定解除 そのチャンネルの自動リアクション設定を解除します
➕ 再付与 リアクションが付いていない既存メッセージ（最大200件）に、 現在の設定でリアクションを付与します

再付与の仕様

  • 対象はコマンドを実行したチャンネルの既存メッセージ（最大200件）
  • 設定済みの絵文字が1つも付いていないメッセージにのみ付与します
  • Bot のメッセージはスキップします
  • レート制限対策のため、10件ごとに少し待機しながら処理します
  • 実行中はボタンの多重実行を防止します

💡 活用例: 提案チャンネルで 👍/👎 リアクションを自動追加、質問チャンネルで ❓ リアクションを追加するなど。

注意事項

  • 設定はチャンネルごとに個別です。他のチャンネルには影響しません
  • 絵文字を再登録すると、以前の設定は上書きされます
  • 設定解除はパネルの「🗑️ 設定解除」ボタンから行えます（コマンドの引数なし実行では解除されません）
  • Bot のメッセージには自動付与されません
  • 既存メッセージへの一括付与には、Bot に「リアクションの追加」権限が必要です
