王様ゲーム

VCにいるメンバーから王様をランダム選出して遊べるゲーム

💡 王様ゲームとは？ VC に参加中のメンバーからランダムで「王様」を選出する ゲーム機能です。王様以外のメンバーには自動で 「家来」の番号が振られます。

概要

/王様 を実行すると、そのサーバーの VC に 参加中のメンバー（見学・観戦 タグの付いていないメンバー）からランダムで 1 人を選び、 王様パネルを表示します。

  • 王様はランダムに選出され、プロフィール画像付きで表示
  • 過去の王様は履歴として自動記録
  • 王様以外の対象メンバーはシャッフルして家来番号を付与
  • ボタンは Bot の再起動後も動作（永続ビュー）
  • 1サーバーで複数の王様パネルを並行運用可能

コマンド

/王様
VC にいる対象メンバーから王様をランダム選出し、 王様パネルを表示します。
ユーザー用

王様パネルの表示

王様（embed 1）

タイトル「王様に選ばれたのは...」に、選出されたメンバーの メンションとプロフィールリンク（保存済みプロフィールがある場合）、 プロフィール画像が表示されます。

過去の王様（embed 2）

これまでに王様として選ばれたメンバーの一覧が表示されます。 フッターには現在の対象人数に応じた 「家来番号：1番～〇番」が表示されます （〇 = 対象人数 − 1）。

家来（embed 3）

「家来」ボタンを押すと表示されます。王様以外の対象メンバーが シャッフルされ、1番：@メンバー の形式で 家来番号が振られます。

パネルのボタン

ボタン 説明
🔄 再表示 現在の状態を保持したままパネルを新しいメッセージとして 再投稿します（元のメッセージは削除）
👑 王様選出 現在の王様を「過去の王様」に追加して、新しい王様を ランダム選出します。家来リストはリセットされます
🏠 家来 王様以外の対象メンバー全員にランダムな家来番号を振り、 家来リストを表示します

王様選出のルール

  • 見学・観戦タグの付いていない VC 参加メンバーが対象
  • 過去に王様になったメンバーは選出対象から除外されます
  • 全員が王様経験済みになった場合は履歴をリセットし、 全員が再度対象になります
  • 対象メンバーがいない場合はエラーメッセージを表示します

再起動・複数パネルについて

王様パネルのボタンは永続ビューとして実装されており、 Bot の再起動後も過去に送信したパネルのボタンがそのまま動作します。 ゲームの状態（現在の王様・過去の王様・家来）は embed の メンションから復元されるため、DB やメモリに依存せず、 同じサーバー内で複数の王様パネルを同時に運用できます。

関連機能

ゲームへの参加 / 不参加の切り替えは 見学パネル から行えます。 見学・観戦タグの付いたメンバーは王様の選出対象から 除外されます。
