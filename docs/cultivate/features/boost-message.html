ブーストメッセージ

サーバーメンバーのブーストを自動でお祝い

💡 ブーストメッセージとは？ サーバーメンバーが Nitro ブーストした際に、設定したチャンネルへ 自動でメッセージを送信する機能です。 日中と深夜で内容を切り替えられ、アイコン入りの カード画像を添付することもできます。

概要

ブーストメッセージ機能は、メンバーがサーバーをブーストしたときに お祝いメッセージを自動送信します。 設定した深夜時間帯（デフォルト: 22:00〜06:00）にブーストした場合は 深夜用のメッセージに自動で切り替わります。

  • 送信チャンネルは1つまで設定可能（未設定時は送信なし）
  • ブーストメッセージ / 深夜メッセージを個別に設定
  • メッセージを空欄にすると、その時間帯は送信されません
  • アイコン入りカード画像（PNG）の添付を ON/OFF できます
  • ブースト中の人が追加でブーストした場合も検知して送信します
  • サーバーのブースト数が増えた（レベルアップ）際の通知も設定できます
  • Bot アカウントのブーストは対象外です

設定方法

設定パネルを開く

  1. コマンドを実行 /ブーストメッセージ設定
  2. 基本設定を行う 「⚙️ 基本設定」ボタンから送信チャンネル・メッセージ・深夜時間帯を設定
  3. 通知・カード設定（任意） 「🎛️ 通知・カード設定」ボタンからブースト数増加通知とカード表示を ON/OFF

設定項目

設定項目 必須 説明
送信チャンネル 任意 メッセージを送信するテキストチャンネル（1つだけ・未選択可）
ブーストメッセージ 任意 ブーストした際のメッセージ（空欄時は送信しない）
深夜メッセージ 任意 深夜にブーストした際のメッセージ（空欄時は送信しない）
深夜開始時間 必須 深夜時間帯の開始時刻（HH:MM 形式、例: 22:00）
深夜終了時間 必須 深夜時間帯の終了時刻（HH:MM 形式、例: 06:00）
ブースト数増加通知 任意 サーバーのブースト数が増えた（レベルアップ）時に通知するか
カード表示 任意 アイコン入りカード画像（PNG）をメッセージに添付するか

メッセージに使えるプレースホルダー

プレースホルダー 置き換え内容
{usernickname} ブーストしたメンバーのサーバー内表示名
{username} ブーストしたメンバーのユーザー名
{usermention} ブーストしたメンバーへのメンション
{guildname} サーバー名
{boostcount} 現在のサーバーのブースト数

カード画像

カード表示を ON にすると、ブーストしたメンバーのアイコンを丸く切り抜いて 背景画像に合成したカード画像（840×420px）が添付されます。 中央にアイコンと「🎉 ブーストありがとう！」+ 表示名、 現在のブースト数が描画されます。

  • 背景画像は data/img/boost_default_card.png に置くことで カスタマイズ可能（無い場合は紫の単色背景）
  • 背景の明るさに応じてテキスト色が自動で切り替わる
  • 表示名が長い場合はカード幅に収まるよう自動で縮小
  • ブースト数はカード下部に「現在 N ブースト」と表示

検知の仕組み

ブーストは以下の2つのイベントで検知され、それぞれ役割が分かれています。

  • メンバー更新（個人カード送信）: メンバーの premium_since の変化を検知してブーストメッセージを送信します。 初回ブースト（None → 開始）だけでなく、ブースト中の人が 追加でブーストした場合（日時が更新）も検知してカードを送信します。
  • サーバー更新（ブースト数増加通知のみ）: サーバーの ブースト数が増えた（レベルアップ）場合に通知します。個人カードの 送信は行いません。

個人カードの送信はメンバー更新イベントに一本化されているため、 2つのイベントが同時に発生してもメッセージが重複したり取りこぼしたりすることは ありません。同一メンバーが短時間に連続でブーストした場合の重複通知は、 60秒間の cooldown で防止されます。

コマンド一覧

/ブーストメッセージ設定
ブーストメッセージの設定パネルを開きます。 基本設定（チャンネル・メッセージ・深夜時間帯）と 通知・カード設定が行えます。
管理者専用

注意事項

  • 送信チャンネルが未設定の場合はメッセージは送信されません
  • ブースト・深夜メッセージが空欄の時間帯は送信されません（カード画像も添付されません）
  • 深夜時間帯は日を跨ぐ設定（22:00〜06:00 など）にも対応しています
  • 開始時刻と終了時刻が同じ場合は深夜時間帯なしとして扱われます
  • ブースト数を増やす際は上から「サーバーブースト」メニューから行います（本機能は検知・通知のみ行います）
