インチャ掃除

VC が空になったらチャンネル内のメッセージを自動削除

💡 インチャ掃除とは？ VC / ステージチャンネルから全員が退出したタイミングで、 そのチャンネル内のメッセージを自動的に削除する機能です。 インチャ（VC 内チャット）に溜まったプロフィールや雑談を、 誰もいなくなったタイミングで自動的にキレイにできます。

概要

/インチャ掃除設定 で作成した設定プリセットに従って、 対象チャンネルの人数が 0 になったらチャンネル内のメッセージを 一括削除します。設定は複数作成でき、チャンネルごとに 異なる条件を割り当てられます。

  • 対象チャンネルは複数選択可能（VC / ステージ）
  • 削除前に遅延時間を設定可能（デフォルト 0 秒）
  • 「空」の判定に Bot を含めるか切り替え可能
  • 設定は DB に保存され、Bot の再起動後も保持
  • 起動時にすでに空のチャンネルも自動で掃除

コマンド

/インチャ掃除設定
インチャ掃除の設定プリセット一覧を表示します。 新規作成・編集・削除ができます。
管理者専用

設定方法

設定一覧を開く

/インチャ掃除設定 を実行すると、現在登録されている 設定プリセットの一覧が表示されます。
このコマンドは管理者権限を持つメンバーのみ実行可能です。

新規作成

  1. 「➕ 新規作成」を押す 新しい設定プリセットが作成され、編集パネルが表示されます
  2. 「⚙️ 基本設定」を押す 基本設定モーダルが開くので、各項目を入力します
  3. 「🟢 有効化」を押す 設定を有効にすると自動削除が動作します

基本設定の項目

基本設定は 1 つのモーダルでまとめて 設定できます（Component v2 対応）。

設定項目 説明
📝 設定名 プリセットの名前（管理用・必須）
📌 対象チャンネル 掃除するチャンネルを選択（VC / ステージ・ 複数選択可・未選択可）
🤖 空条件の人数にBotを含む チェックボックス。OFF（デフォルト）の場合は Bot だけが残っていても「空」と判定。 ON の場合は Bot がいる間は掃除しない
⏱️ 削除遅延秒数 人数が 0 になってから削除するまでの待機秒数 （デフォルト 0 秒・0 以上の整数）

編集パネルの操作

ボタン 説明
⚙️ 基本設定 基本設定モーダルを開いて項目を編集します
🔴 無効化 / 🟢 有効化 設定の有効・無効を切り替えます
◀️ 戻る 設定一覧に戻ります

自動削除の動作

  1. 退出を検知 対象チャンネルから誰かが退出（または別チャンネルへ移動）すると、 空かどうかをチェックします
  2. 空の判定 対象チャンネルの人数が 0（または Bot を除いて 0）なら 掃除を開始します
  3. 遅延待機 削除遅延秒数が設定されている場合はその間待機し、 再度空かどうかを確認してから削除します （間に人が入った場合はキャンセル）
  4. メッセージ削除 チャンネル内の全メッセージを一括削除します

⚠️ 注意: 削除したメッセージは元に戻せません。 重要な内容が残っている可能性があるチャンネルを対象にする場合は、 削除遅延秒数を設定して誤削除を防ぐことを推奨します。

関連機能

チャンネル内の自分のメッセージだけを削除したい場合は、 自己メッセージ削除 をご利用ください。 こちらは誰でも実行できます。
