でりえんカレンダー

DeLien Calender の予定をDiscordへ自動通知

💡 でりえんカレンダーとは？ DeLien Calender に 登録した予定の作成・編集・削除・開始前リマインドを 指定したチャンネルへ自動で投稿する機能です。 予定の取得はBotが約30秒ごとに行います。

概要

でりえんカレンダー連携は、DeLien Calender の Web API（v1）を 利用して予定の通知をDiscordへ配信します。 通知先のチャンネルはサーバーごとに、 通知する内容（対象イベント・リマインド時刻・通知本文）は カレンダーごとに設定できます。

APIトークンはユーザー単位（全サーバー共通）で 保存されるため、一度登録すれば 同じアカウントで管理しているサーバーすべてで利用できます。 カレンダー所有者がサーバーで共有したあとは、 そのサーバーの管理者であれば誰でも 設定を変更できます。

機能一覧

機能 説明
トークン管理 DeLien Calender のAPIトークンを登録・削除（暗号化して保存／登録した本人のみ表示）
予定の自動通知 予定作成・編集・削除・開始前リマインドを指定チャンネルへ投稿
サーバーごとの通知先 カレンダーごとに投稿先チャンネルと有効・無効を設定
共有設定の共同管理 カレンダー所有者が共有したあとは、そのサーバーの管理者なら誰でも設定を変更
投稿者設定 Webhook投稿の表示名・アイコンをサーバーごとに変更
トリガー別の通知本文 予定作成・編集・削除・開始前リマインドで本文を個別に設定
予定一覧 /でりえんカレンダー で予定を期間指定して表示

使い方

1. APIトークンを発行する

DeLien Calender の管理画面でAPIトークンを発行します。 トークンはカレンダーの所有者（作成者）のみが 発行できます。発行時に一度だけ表示されるので、 コピーしておいてください。

2. トークンを登録する

/でりえんカレンダー設定 を実行し、 「🔑 トークン登録」からAPIトークンを入力します。 登録したトークンは全サーバー共通で、 登録した本人だけが表示・管理できます （他の管理者にはトークンの状態も表示されません）。

3. サーバーでカレンダーを共有する

「カレンダー設定」から、共有するカレンダーの 送信先チャンネルを設定し、 通知を有効にします。 送信先を設定していないカレンダーはそのサーバーへ 通知されません。

4. 以降は管理者なら誰でも設定を変更できる

共有したあとは、そのサーバーの管理者であれば 誰でも送信先チャンネル・有効／無効・ 投稿者などを変更できます。 設定の変更はカレンダー所有者のトークンでAPIへ同期されるため、 変更した人がトークンを持っている必要はありません。

設定画面の操作

メインパネル:

  • カレンダー設定: カレンダーごとの通知設定を開く
  • 🔑 トークン登録 / トークン再登録: 自分のトークンを登録・差し替え
  • トークン削除: 自分のトークンを削除

カレンダー設定ページ（全ページ共通の操作）:

  • 前へ / 次へ: カレンダーを切り替え
  • 通知イベント（セレクト）: 通知するイベントを選択（カレンダー共通）
  • 送信先チャンネル: 通知先を選択（サーバーごと）
  • 本文/リマインド: 予定作成・予定編集・予定削除・開始前リマインドの本文をそれぞれ個別に設定し、何分前に通知するかを指定（カレンダー共通）
  • 投稿者設定: Webhook投稿の表示名とアイコン（サーバーごと）
  • 通知: 有効 / 通知: 無効: そのサーバーでの通知の切り替え
  • 設定を削除: そのサーバーの共有設定を削除
  • 戻る: メインパネルへ戻る

⚠️ 注意: トークンが失効している場合は 401 が返り、 自動的に「失効」として記録されます。 新しいトークンを登録し直してください。

トークンをリセットしたとき

「トークン削除」ではトークンのみを削除し、 各サーバーの共有設定（送信先チャンネル・有効設定・ 投稿者設定）は保持されます。 同じアカウントでトークンを再登録すると、 各サーバーで操作することなく元の設定のまま通知が再開します。

トークンを再登録すると、その場で新しいトークンへ購読を 貼り直すため、再起動や定期同期を待つ必要はありません。 古いトークン側の購読は自動的に解除されます。 なお、トークンは約20秒ごとにデータベースから読み直すため、 別のプロセスで更新した場合も再起動なしで反映されます。 古いトークンで認証エラーが返っても、 差し替え後の新しいトークンが失効扱いになることはありません。

パネルとログにはトークンの識別子 （トークンのSHA-256の先頭8文字）が表示されます。 「いまどのトークンで処理しているか」をこれで確認できます。

設定のスコープ

APIの購読はトークン単位で置き換わるため、 通知の中身はカレンダー共通、送信先はサーバーごとになります。

設定項目 スコープ
通知イベント / 通知本文（トリガー別）/ リマインド分数 カレンダー共通（同じカレンダーを使う全サーバーに反映）
送信先チャンネル / 有効・無効 / 投稿者名・アイコン サーバーごと

トリガー別の通知本文

「本文/リマインド」から、次の4種類の本文を個別に設定できます。 空欄にしたイベントは本文なし （Embedのみ）で投稿されます。

入力欄 対象
作成時の本文 予定が作成されたとき
編集時の本文 予定が編集されたとき
削除時の本文 予定が削除されたとき
リマインド時の本文 開始前リマインドのとき

メンションは本文に直接書きます （例: @everyone、 <@&ロールID>）。 旧バージョンで設定した共通のメンション本文は、 すべてのイベントの本文として引き継がれます。

投稿方法

投稿はサーバー内に作成される 「DeLien Calendar」という名前のWebhookから行われます （既定の表示名は DeLien Calendar、 アイコンはサービスアイコン）。 投稿者設定を変更すると、その名前・アイコンで投稿されます。

Webhookを作成できない場合は、Botの通常メッセージとして 投稿されます。

注意事項

  • APIトークンはカレンダーの所有者のみ発行できます
  • トークンを登録した本人だけがトークンの状態を確認・変更できます（他の管理者には表示されません）
  • 購読の登録はカレンダーの所有者であるアカウントでのみ行えます（所有者以外は拒否されます）
  • 予定の取得は約30秒間隔です（登録から通知まで最大30秒ほどかかります）
  • 予定が削除された場合も、削除の通知がそのまま投稿されます
  • 「設定を削除」でサーバーの共有を解除すると、そのサーバーへの通知は停止します（カレンダー共通設定は残ります）
  • Webhookは投稿先チャンネルごとに作成されるため、Botに「Webhookの管理」権限が必要です
