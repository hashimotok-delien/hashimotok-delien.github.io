📜 コマンド一覧

ねくさす⋆˚ʚɞ で使用できる全コマンドの一覧です。 管理者専用 ユーザー用

コマンド

🔧 設定・管理

/設定パネル
設定用パネルを表示します。コマンド接頭辞の変更などが行えます。
管理者専用
/bot管理
Bot の管理コマンド。導入サーバー一覧の表示や退出などが行えます。
Bot所有者専用

📸 プロフィール保存

/プロフ設定
プロフィール保存機能の設定パネルを開きます。プロフチャンネルの設定や、操作可能ロールの設定ができます。
管理者専用

🌐 マイプロフ（鯖間プロフ）

/マイプロフ設定
マイプロフ機能の設定パネルを開きます。プロフ送信方法（DM / スレッド）や、鯖間取得・保存の許可などをプリセット単位で設定できます。
管理者専用
/マイプロフパネル設置
マイプロフパネルを現在のチャンネルに設置します。パネルから「他鯖取得」「保存取得」「保存」が操作できます。
管理者専用

💬 交流計測

/交流計測設定
VC 交流計測機能の設定パネルを開きます。有効な VC / カテゴリの指定や、記録条件をプリセット単位で設定できます。
管理者専用
/交流計測ランキング
交流計測ランキングのパネルを表示します。総合・異性間・同性間など、プリセットされたランキングを確認できます。
ユーザー用
/交流計測記録パネル
交流計測記録パネルを現在のチャンネルに設置します。ユーザーはパネルのボタンから自身の交流記録を確認できます。
管理者専用

🏆 ランクシステム

/ランク [@ユーザー]
自分または指定ユーザーのランクを表示します。 画像式のランクカードで表示されます。 表示対象は ⭐ メイン設定されたプリセットです。
ユーザー用
/ランキング [期間]
サーバー内の VC XP ランキング TOP10 を表示します。 期間は「週間」「月間」を指定できます（省略時は全期間）。
ユーザー用
/ランク設定
ランクシステムの設定パネルを開きます。プリセットの作成・編集・削除ができます。
管理者専用
