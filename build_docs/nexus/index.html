ねくさす⋆˚ʚɞ とは

ねくさす⋆˚ʚɞ は、Discord サーバーの交流を活性化するために開発された多機能 Bot です。 プロフィール保存・鯖間プロフ取得、VC 交流計測ランキング、VC 滞在時間のランクシステムなど、 界隈サーバー運営に必要な機能を1つにまとめて提供します。

バージョン 1.0.0 ／ モジュール: discord.py 📋 更新履歴を見る

機能一覧

📸 プロフィール保存

メッセージリンクからプロフィールを保存・再表示。保存したプロフはいつでも呼び出せます。

🌐 マイプロフ（鯖間プロフ）

イベ鯖で残っているプロフを他鯖から引用、またはDMに保存して持ち運べます。パネル設置でボタン操作。

💬 交流計測

VC の同席記録から「たくさんの人と喋った人」を計測。総合・異性間・同性間のランキングを表示できます。

🏆 ランクシステム

VC 滞在時間に応じて XP を獲得しレベルアップ。ミュート勢も安心の設計で、数式自由設定・画像ランクカード対応。

詳しく見る →

⚙️ 設定パネル

プリセットの有効化・メイン設定など、ランクシステムの各種設定を一元的に管理できるパネル。

🖥️ サーバー管理

管理コマンド（/bot管理）から Bot の導入サーバー一覧や動作状況の確認などができます。
