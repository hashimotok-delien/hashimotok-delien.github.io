🚀 導入方法

ねくさす⋆˚ʚɞ をサーバーに導入する手順を説明します。

導入の流れ

  1. サポートサーバーに参加 下記のリンクからサポートサーバーに参加してください。
    サポートサーバーへ
  2. ルールを確認・同意 サポートサーバー内のルールを確認し、同意してください。
  3. 導入チケットを送信 サポートサーバー内のチケットシステムから導入リクエストを送信してください。 導入にはサーバーの管理者権限が必要です。
  4. Bot が参加 チケット処理後、Bot があなたのサーバーに参加します。

💡 注意: ねくさす⋆˚ʚɞ は界隈サーバー専用の無料配布 Bot です。導入にはサーバー管理者権限が必要です。

初期設定

Bot が参加したら、以下の設定を行ってください。

1. プロフィール機能の設定

管理者権限を持つアカウントで、以下のコマンドを実行します。 

/プロフ設定

プロフィール保存機能の設定パネルが表示されます。プロフチャンネルの設定や、操作可能ロールの設定を行います。

2. マイプロフ（鯖間プロフ）の設定

マイプロフ機能を利用する場合は、以下のコマンドを実行します。

/マイプロフ設定

プロフ送信方法（DM / スレッド）や、鯖間取得・保存の可否をプリセット単位で設定できます。 設定後は /マイプロフパネル設置 でパネルをチャンネルに設置します。

3. 交流計測の設定

VC 交流計測を利用する場合は、以下のコマンドを実行します。

/交流計測設定

計測対象の VC チャンネル・カテゴリや記録条件をプリセット単位で設定できます。

4. ランクシステムの設定

VC ランクシステムを利用する場合は、以下のコマンドを実行します。

/ランク設定

プリセットを作成し、VC の計測条件・成長曲線・レベルアップ通知などを設定します。

📸 プロフィール

プロフの保存・再表示、鯖間プロフ取得を設定します。

💬 交流計測

VC での交流人数を計測・ランキング化します。

🏆 ランクシステム

VC 滞在時間に応じたレベルアップを設定します。
