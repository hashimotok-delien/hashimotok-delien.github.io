ウェルカムメッセージ

新規参加者に自動でメッセージとカード画像を送信

💡 ウェルカムメッセージとは？ サーバーに新規ユーザーが参加した際に、設定したチャンネルへ 自動でメッセージを送信する機能です。 日中と深夜で内容を切り替えられ、アイコン入りの カード画像を添付することもできます。

概要

ウェルカムメッセージ機能は、メンバーがサーバーに参加したときに あいさつメッセージを自動送信します。 設定した深夜時間帯（デフォルト: 22:00〜06:00）に参加した場合は 深夜用のメッセージに自動で切り替わります。

  • 送信チャンネルは1つまで設定可能（未設定時は送信なし）
  • 日中メッセージ / 深夜メッセージを個別に設定
  • メッセージを空欄にすると、その時間帯は送信されません
  • アイコン入りカード画像（PNG）の添付を ON/OFF できます
  • Bot アカウントの参加は対象外です

設定方法

設定パネルを開く

  1. コマンドを実行 /ウェルカムメッセージ設定
  2. 基本設定を行う 「⚙️ 基本設定」ボタンから送信チャンネル・メッセージ・深夜時間帯を設定
  3. カード表示を設定（任意） 「🎴 カード設定」ボタンからカード画像の表示を ON/OFF

設定項目

設定項目 必須 説明
送信チャンネル 任意 メッセージを送信するテキストチャンネル（1つだけ・未選択可）
日中メッセージ 任意 日中に参加した際のメッセージ（空欄時は送信しない）
深夜メッセージ 任意 深夜に参加した際のメッセージ（空欄時は送信しない）
深夜開始時間 必須 深夜時間帯の開始時刻（HH:MM 形式、例: 22:00）
深夜終了時間 必須 深夜時間帯の終了時刻（HH:MM 形式、例: 06:00）
カード表示 任意 アイコン入りカード画像（PNG）をメッセージに添付するか

メッセージに使えるプレースホルダー

プレースホルダー 置き換え内容
{usernickname} 参加者のサーバー内表示名
{username} 参加者のユーザー名
{usermention} 参加者へのメンション
{guildname} サーバー名

カード画像

カード表示を ON にすると、参加者アイコンを丸く切り抜いて 背景画像に合成したカード画像（840×420px）が添付されます。 中央にアイコンと「ようこそ」+ 表示名が描画されます。

  • デフォルトの背景画像: data/img/welcome_default_card.png
  • カードの文字は背景が明るい場合でも読めるよう黒文字＋白影で描画
  • 表示名の絵文字はカラーで描画（data/fonts/NotoColorEmoji.ttf）
  • 日本語フォントに無い文字（Yi文字「꒳」など）は、ランクカードと同じ補完フォント群から文字ごとに最適なフォントを自動選択して描画 （MSYI.TTF / NotoSansYi-Regular.ttf / NotoSansSymbols* / NotoSansMath-Regular.ttf / NotoSansBengali-Regular.ttf / NotoSans-Regular.ttf）
  • 「🐈‍⬛」のようなZWJ合成絵文字もカラーで描画可能
  • テンプレート画像は将来のカスタマイズに対応予定

コマンド一覧

/ウェルカムメッセージ設定
ウェルカムメッセージの設定パネルを開きます。 基本設定（チャンネル・メッセージ・深夜時間帯）と カード表示の設定が行えます。
管理者専用

注意事項

  • 送信チャンネルが未設定の場合はメッセージは送信されません
  • 日中・深夜メッセージが空欄の時間帯は送信されません（カード画像も添付されません）
  • 深夜時間帯は日を跨ぐ設定（22:00〜06:00 など）にも対応しています
  • 開始時刻と終了時刻が同じ場合は深夜時間帯なしとして扱われます
