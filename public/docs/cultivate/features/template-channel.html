テンプレチャンネル設定

チャンネル構成をテンプレート化して一括作成

💡 テンプレチャンネル設定とは？ チャンネル名・タイプ・オプションをまとめた「テンプレート」を ユーザー単位で登録し、任意のカテゴリに一括でチャンネルを作成できる機能です。 登録したテンプレートはサーバーをまたいで使用可能です。

概要

テンプレチャンネル設定は、よく使うチャンネル構成を 「テンプレチャンネルグループ」として保存し、 新しいサーバーやカテゴリにチャンネルを一括作成するための機能です。 テンプレートはユーザー単位で管理されるため、 あるサーバーで登録したテンプレートを別のサーバーでもそのまま利用できます。

機能一覧

機能 説明
テンプレート管理 ユーザーごとに最大3グループまで作成可能
チャンネル登録 1グループに最大20チャンネルまで登録可能
サーバー横断利用 登録したテンプレートをサーバーをまたいで使用可能
一括作成 指定カテゴリに登録済みチャンネルを一括作成

チャンネルタイプ

各チャンネルには以下のタイプを設定できます。

タイプ 説明
テキスト 通常のテキストチャンネル
VC ボイスチャンネル
フォーラム フォーラムチャンネル
ステージ ステージチャンネル

チャンネルオプション

オプション 説明
デフォルト 通常のチャンネルとして作成
年齢制限 NSFWチャンネルとして作成

設定の流れ

1. グループ一覧

/テンプレチャンネル設定 を実行すると テンプレチャンネルグループの一覧が表示されます。 1ページに1グループずつ表示され、以下のボタンで管理します。

  • ➕ 新規作成: 新しいグループを作成
  • ✏️ 編集: 表示中のグループを編集
  • 🗑️ 削除: 表示中のグループを削除（YES/NO確認あり）

2. 新規作成

「➕ 新規作成」を押すと設定名を入力するModalが表示されます。 作成後は自動的に編集画面へ移動します。

3. 編集画面

編集画面では以下の操作ができます。

  • 📝 基本設定: グループ名を変更
  • 📄 テンプレ設定: チャンネルの追加・編集・削除
  • 🚀 作成: カテゴリを選んでチャンネルを一括作成
  • 💾 保存: 変更を確定
  • ↩️ 戻る: グループ一覧へ戻る

⚠️ 注意: チャンネルの追加・編集・削除は 💾 保存 ボタンを 押すまで確定されません。

4. チャンネル設定

「📄 テンプレ設定」を押すとチャンネル一覧が表示されます。 各チャンネルには以下の項目を設定できます。

  • チャンネル名: 作成するチャンネルの名前（必須）
  • チャンネルタイプ: テキスト / VC / フォーラム / ステージ
  • チャンネルオプション: デフォルト / 年齢制限
  • アナウンスチャンネル: テキストのみ有効

5. チャンネル作成

「🚀 作成」を押すと作成先カテゴリを選択するModalが表示されます。 カテゴリを選択すると、登録済みのチャンネルが一括で作成されます。 作成結果（成功・失敗）が表示されます。

コマンド一覧

/テンプレチャンネル設定
テンプレチャンネルグループの一覧を表示します。 グループの作成・編集・削除・チャンネル一括作成が行えます。
管理者専用

注意事項

  • テンプレートはユーザー単位で管理され、サーバーをまたいで使用できます
  • ユーザーごとに最大3グループまで作成可能です
  • 1グループに最大20チャンネルまで登録可能です
  • 年齢制限オプションはNSFWチャンネルとして作成されます
  • アナウンスチャンネルはテキストタイプでのみ有効です
