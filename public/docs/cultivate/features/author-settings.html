投稿者設定

Webhook 投稿時の表示名・アイコンをプリセットとして一元管理

💡 投稿者設定とは？ 吊下げメッセージや予約投稿など、Webhook を使用して投稿する際の 表示名・アイコン をプリセットとして保存できる機能です。 事前に投稿者を作っておけば、名前やアイコンを変更したいときに 各設定を個別に触ることなく一括で反映できます。

概要

投稿者設定機能は、Webhook 投稿時の投稿者情報（表示名・アイコン）を サーバーごとにプリセットとして管理するシステムです。 吊り下げメッセージや予約投稿の編集画面でプリセットを選択するだけで、 その投稿者名・アイコンが自動で適用されます。

プリセットを編集すると、そのプリセットを使用している 吊り下げ・予約投稿すべてに変更が反映されるため、 「アイコンを変更したいけど、設定した場所が多すぎて…」といった 手間を解消できます。

使い方

スラッシュコマンド

管理者権限を持つメンバーは以下のコマンドを実行します：

/投稿者設定

投稿者プリセットの一覧パネルが表示されます。

プリセットの作成

  1. 一覧パネルを開く /投稿者設定 を実行し、「➕ 新規作成」ボタンをクリック
  2. 各項目を入力 設定画面で以下の項目を入力します
  3. 保存 忘れずに「💾 保存」をクリック

設定項目

項目 必須 説明
🆔 ID 必須 プリセットを識別するための ID（重複禁止・変更可能）
📛 設定名 必須 管理用のプリセット名（例: 公式BOT通知）
👤 表示名 任意 Webhook 投稿時に表示される名前（省略時は Bot 名）
🔗 アイコンURL 任意 Webhook 投稿時に表示されるアイコンの URL
📤 画像ファイル 任意 アイコンを画像ファイルから直接アップロード（アイコンURLと併用可）

管理画面の操作

ボタン 説明
➕ 新規作成 新しい投稿者プリセットを作成
✏️ 編集 選択中のプリセットの設定画面を開く
🗑️ 削除 プリセットを削除（削除セレクターから選択）
💾 保存 変更内容を保存
🔙 戻る 一覧パネルに戻る（未保存の変更がある場合は自動保存）

⚠️ 制限: プリセットは1サーバーにつき最大24件 まで作成できます。

使用できる機能

作成した投稿者プリセットは、以下の機能の「👤 投稿者設定」から選択できます：

機能 説明
📌 吊下げメッセージ 吊り下げの編集 → 「👤 投稿者設定」でプリセットを選択可能
📅 予約投稿 予約投稿の編集 → 「👤 投稿者設定」でプリセットを選択可能

プリセットを選択した場合、個別設定の名前・アイコンを入力する必要はありません。 プリセット未選択の場合は従来どおり手動で名前・アイコンを設定できます。

💡 活用例: 「公式BOT」「お知らせ」「イベント告知」など 用途ごとにプリセットを作っておけば、アイコンを差し替えたいときも プリセットを1回編集するだけで全機能に反映されます。
